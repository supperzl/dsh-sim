# Screenshots

`hero.png` and `device-picker.png` are **real captures** of the DSH desktop app running
dsh-sim — not mockups.

How they were taken:

- a fresh, empty conversation (no project content), with the left sidebar collapsed so no
  session titles are visible;
- the simulator tab opened from the Start page and connected to an iOS Simulator;
- the picker shot filters the list with "iPhone" so only simulator models are shown.

They contain no conversation text, file paths, device identifiers or personal data.
`icon.png` is generated by `scripts/render-docs-images.py`.
